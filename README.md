# UniqueItemTransferPlugin

A simple plugin to transfer unique items between bots.



## Features

* Transfer unique items
* Batch processing
* Confirmation system



## License

Apache License 2.0



## About the Plugin



Transfer unique items between bots with smart matching and confirmation. It also includes the possibility to adjust the amount of items to transfer so to not overload and facilitate the trade before sending.

First of all, I am not a coder, indeed, this project was entirely built with the help of copilot. It got me to solve the transfer from my main account to my deposit of only unique items with the primarily purpose of not clattering my collection. I wish it could be of use for everyone. Have fun!
